The Action Policy Value

UCT(s, a) = Q(s, a) + c * sqrt(ln(N_p) / N_c)

  • Q(s, a): Estimated expected commercial yield + sustainability reward.
  • N_p: Total visits to parent game state.
  • N_c: Visits to candidate tile action branch.
  • c constant: Dynamic exploration parameter tuned for weather volatility.
